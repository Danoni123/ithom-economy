# ITHom economy

Сайт на React (Vite) без серверной части — только фронтенд.
Чёрно-бело-серая гамма, свечные графики, адаптация под телефоны.

## Запуск

```bash
npm install
npm run dev        # режим разработки → http://localhost:5173
npm run build      # сборка в папку dist/ (можно выложить на любой хостинг)
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 18+.

## Что внутри

- **Шапка** — узкая, липкая, с индикатором готовности проекта и мобильным меню.
- **График** — три вкладки:
  - «Капитализация» — пока не активна, значение $0;
  - «Цена ITC» — токен, пока не активен, цена $0.00;
  - «Прогресс развития» — свечи (зелёные/красные) за 1–20 сентября 2026,
    одна свеча = 4 часа, резкие рывки и откаты, сейчас 30% из 100%.
- **Управление графиком**
  - масштаб: колесо мыши, щипок пальцами, кнопки «−» / «+»;
  - сдвиг: перетаскивание; «Вписать» возвращает исходный вид;
  - «0–100» — шкала от 0 до 100%, чтобы видеть весь путь проекта;
  - рисование: линия, прямоугольник, горизонтальный уровень, 4 цвета;
  - выделение: клик по объекту → перетаскивание, изменение размера за точки,
    удаление кнопкой-корзиной или клавишей Delete; Esc — отмена.
  - рисунки сохраняются в браузере (localStorage).
- **Новости** — 3 карточки.
- **Футер**.

## Как поменять данные

| Что | Где |
| --- | --- |
| Текущий % готовности | `src/data/chartData.js` → `PROJECT_PROGRESS` |
| Форма графика (подъёмы и откаты) | `src/data/chartData.js` → `WAYPOINTS` |
| Период и размер свечи | `src/data/chartData.js` → `START_MS`, `STEP_HOURS`, `CANDLES` |
| Новости | `src/data/news.js` |
| Цвета, шрифты, размеры | `src/styles.css` (переменные в `:root`) |

Шрифты (Onest, Unbounded) подгружаются с Google Fonts; без интернета
подставятся системные.
